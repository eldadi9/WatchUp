```markdown

## Completed
## Files Created
## Files Updated
## Brand Direction
## README Changes
## Design System
## Asset Structure
## Validation
## TODO
## Git Status

- Push:

```

## Implementation run (Phase 3+)

```markdown
# Brand Implementation Report
## Brand Sources Used
## Files Changed
## App Areas Updated
## Logo / Icon Updates
## Global Tokens Applied
## Components Updated
## Dashboard Updated
## Mobile / PWA Updated
## README / GitHub Updated
## Validation
## Build / Tests
## Remaining TODO
## Git Status
- Branch:
- Commit:
- Push:
```

In both cases, the TODO and Git Status sections are the parts most likely to actually
get read carefully — keep them honest and specific rather than padding the rest of the
report.
